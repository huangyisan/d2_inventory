暗黑破坏神2 · 收藏台账

选择你的存档文件夹开始。
玩完游戏存档后，点「重新读取」即可刷新（⌘R / Ctrl+R）

怎么用

  1. 点「选择存档文件夹」，选中 D2R 的存档目录，浏览器会问一次读取权限。
  2. 页面会扫描目录下所有 .d2s 小号和 .d2i 共享仓库，列出你的暗金与绿装收藏。
  3. 之后每次玩完游戏，回到这个页面点「重新读取」就会刷新。文件夹会被记住，下次打开自动载入。
macOS 存档目录通常在：
~/Library/Application Support/Blizzard/Diablo II Resurrected/
Windows 通常在：%USERPROFILE%\Saved Games\Diablo II Resurrected\
🔒 全程只在你的浏览器本地读取，存档以只读方式打开，不会修改、不会上传到任何地方。
当前浏览器不支持直接打开文件夹（Safari 等）。点「选择存档文件夹」会改用文件选择框， 功能一样，只是每次刷新需要重新选一次。用 Chrome / Edge 体验最好。
物品名称与目录取自游戏数据表；新版本内容若暂无官方中文则显示英文原名。 存档解析全部在本地浏览器中完成，只读不写。
